# Sistema Bancário

Sistema bancário simples desenvolvido em Swift com foco em lógica de programação
e regras de negócio.

## 🛠 Tecnologias utilizadas
- Swift
- Xcode

## 📌 Funcionalidades
- Criação de conta bancária
- Depósito de valores
- Saque com validação de saldo
- Consulta de saldo
- Menu interativo

## 🧠 Conceitos aplicados
- Variáveis e constantes
- Estruturas condicionais
- Funções
- Laços de repetição
- Validação de dados
- Organização do código

## 🎯 Objetivo do projeto
Projeto desenvolvido para fins educacionais e para prática de lógica
e estruturação de sistemas.
